Ant Colony Optimization (ACO)

Ant Colony Optimization is a probabilistic swarm intelligence technique proposed by Marco Dorigo in 1992. It is inspired by the foraging behavior of real ants finding optimal paths through pheromone deposition.

Transition Probability Formula:

P(i → j) = [τ_ij]^α * [η_ij]^β / ∑ ([τ_ik]^α * [η_ik]^β)

  • τ_ij: Pheromone level on edge (i, j). Controlled by Alpha (α).
  • η_ij: Heuristic value (inverse distance 1/d_ij). Controlled by Beta (β).
  • Evaporation (ρ): Prevents premature convergence by reducing pheromones over time.

How to experiment:

  1. Set Alpha = 0 to see purely greedy shortest-path exploration.
  2. Set Beta = 0 to observe movement guided purely by existing pheromone trails.
  3. Adjust Evaporation (ρ): High evaporation forces quick forgetting; low evaporation retains old routes.
